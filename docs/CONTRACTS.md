# Contracts 0.1.0

Contracts → no project references; Core → Contracts; Gameplay → Core + Contracts; Unity client → these three. All shared code is C# 9 / netstandard2.1, compiled from the same source through local UPM packages and noEngineReferences asmdefs. No binary source dependencies.

WorldConfig input: explicit nonzero uint seed, step in (0,60] seconds, world half-extent in (0,10000] metres. These limits are implementation bounds for a diagnostic sample, not ecological data. Null, NaN and infinity are rejected. SimulationStep.Advance outputs immutable WorldSnapshot, increments tick exactly once and calculates elapsed seconds from tick × step. Seeded xorshift32 diagnostic samples wrap unsigned integers explicitly. No dependence on wall clock, frame count or rendered object count. Cross-runtime floating-point equality and long-run numerical accuracy still require Unity tests; replay in this phase uses the exact same commands and config.

MoveProbe input: finite x/z metres within inclusive square bounds. Output: updated snapshot with same stable ID, tick and PRNG sample. Invalid input throws before mutation. Input commands are synchronous; their call order is the event order. There is no event queue or ecological model in phase 00. Gameplay can pause time without preventing probe placement.

StableId uses nonzero ulong; canonical serialized representation is an invariant decimal string to avoid JSON number precision loss. Zero/default struct is invalid for persisted entities and must be rejected by serializers (none yet). IDs are per-world; probe ID 1 is reserved. Future allocation must be deterministic and independent of renderer instances. Identity round-trip is tested. Semantic SchemaVersion accepts only same major and stored minor <= reader minor; future minor/major is rejected, patch does not change shape. Save format version is integer 1; schema is 0.1.0. Both gates must pass. Major-zero breaking changes still increment major explicitly under this policy. No prior saves exist, no migration is needed, and no save serializer/profile system is claimed. Preserve old fixtures and add explicit migration before accepting another save version.

Normalized internal units: seconds (s), metres (m), kilograms (kg). UI localization must not change units or persisted values. Biological parameters remain absent; future numeric model assumptions must carry provenance or an explicit model-assumption label.
